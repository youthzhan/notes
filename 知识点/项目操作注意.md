git流程：
1. git  pull origin master 拉取代码
2. git add . 添加到暂存区
3. git status  查看状态，显示有变更的文件 
4. git diff 比较文件的不同，即暂存区和工作区的差异
5. git commit -m  提交暂存区到本地仓库
    1. feat 新增功能  
    2. fix/to 修复bug
    3. merge 代码合并
    4. test 增加测试   …
6. git push origin 分支名 提交本地仓库代码到远程仓库代码
7. git branch 分支名 创建分支
8. git checkout 分支名 切换分支
9. git checkout  -b 分支名 创建并切换分支




MPS增加默认转封装编排  直播那边或者后端进行操作
直播跳转到mps后自动带入参数：url、编排模版id等。 传入参数需要和直播进行商量
* 通过编排模版id来默认选中创建任务里的选项
* 直播时移固化专用编排就是用于直播时移的一个服务编排，在服务编排列表里面会一直显示。直播时移里一定是系统预设，调用后端接口，获取编排类型（类型包含系统预设、自定义），并渲染上去，禁用启用、编辑、删除，只可以查询和增加。 ✅
* 该服务编排中任务配置的转封装节点中默认使用转封装模板（Transformat-HLS ID=6） ✅
* 当任务从“时移固化”入口进来或者/音视频URL中带有时移固化参数时，创建任务里面的输出信息-输出路径 默认清空，需要用户自行选择方可提交。目前输出路径就是空的，但要保证即使不是空的也要清空。

直播跳转到mps的url和参数怎么获得？
参数：任务类型taskType、需转码文件来源inputType、需转码文件地址inputUrl、关联服务编排pipeline
输出路径 默认清空


转测流程
1. 提交变更单
    1. tea commit之后会弹出变更单页面
    2. 如果是新导入的就选择新导入，如果原本就有就选择原本有的
    3. 填写一系列信息（比如tapd地址，还有变更的页面地址、产品对接人等）
    4. 保存，预览变更单（免HOST预览）
2. 翻译：https://iwiki.woa.com/pages/viewpage.action?pageId=4008495424（commit 时候带 -l zh，一般用中文开发，预览，测试，没问题之后再提翻译）（翻译是需要花钱的，测试过程中可能会有改动，所以测试完再提翻译）
    1. tea dict push  提交词条至翻译仓库
    2. 提翻译单 
    3. tea dict pull 从翻译仓库拉取已翻译词条
    4. tea scan 扫描词条
    5. tea dev -l en 开发调试指定加载具体的语言包
    6. tea build( -l en) 编译所有(指定)语言的独立版本
    7. tea commit （-m “描述”）（-l en/jp/ko）编译并提交发布所有（指定）语言的独立版本

下载文件
 const handleDownload = () => {
    // 模板文件的内容
    const templateContent = t('媒体处理|3\n腾讯大厦|5');
    // 创建一个 Blob 对象
    const blob = new Blob([templateContent], { type: 'text/plain' });
    // 创建一个 URL 对象
    const url = URL.createObjectURL(blob);

    // 创建一个临时的 <a> 元素
    const a = document.createElement('a');
    a.href = url;
    a.download = 'example.txt'; // 设置下载文件的名称

    // 触发下载
    document.body.appendChild(a);
    a.click();

    // 移除临时的 <a> 元素
    document.body.removeChild(a);

    // 释放 URL 对象
    URL.revokeObjectURL(url);
  };
