# formik 表单状态管理
1. 核心痛点• 受控组件 value/onChange 手写繁琐• 校验逻辑散落在各个 handler• 提交时 loading、错误提示、dirty/touched 状态难追踪Formik 把这些全部内置 + 统一。

2. 三大卖点
3. 状态管理：自动收集 values、errors、touched、isSubmitting 等元数据。
4. 校验体系：支持• 同步函数校验（Yup 一键绑定）• 异步校验（远程查重、接口校验）• 字段级 / 表单级双粒度
5. 提交流程：handleSubmit 自带 preventDefault、错误回滚、loading 状态。
6. 周边生态• useFormik Hook：无 JSX 侵入，逻辑复用更方便• FieldArray：动态增删表单项• FastField：性能优化，避免无关重渲染• 与 React Native、Next.js、Ant Design 等无缝配合

5. 何时用 / 何时不用✅ 中后台复杂表单、多步骤表单、需要严格校验❌ 只有一两个简单受控输入 → 用原生或 useState 即可

Formik 速览一句话：React 生态里专门“包办”表单状态、校验与提交的轻量库（v2，MIT，~15 kB gzipped）。
──────────────────一、主要特征
1. 统一状态：values / errors / touched / isSubmitting 自动托管
2. 校验体系：同步函数、Yup 模式、异步远程校验
3. 提交流程：handleSubmit 自带 preventDefault、loading、错误回滚
4. 渲染灵活：支持 组件、useFormik Hook、render-props
5. 周边能力：FieldArray（动态数组）、FastField（性能优化）、withFormik（高阶组件）
──────────────────二、特点 & 优点• 零依赖核心（除 React 外）• 与 Yup 深度集成，声明式校验• 社区成熟，文档丰富，示例多• 支持 React Native• 支持 TypeScript 完整类型推导
──────────────────三、缺点• 包体积比 React Hook Form 大（≈15 kB vs 9 kB）• 受控组件实现，大量字段时可能重渲染（需 FastField 或自行 memo）• 官方已转向维护模式，作者推荐新库 Formik 3 / HouseForm / React Hook Form• 不支持非 React 场景

useMemo、useCallback和useEffect的区别
把三句话先背下来，后面再展开：• useMemo 缓存值（计算结果）。• useCallback 缓存函数引用。• useEffect 执行副作用（DOM 操作、订阅、发请求等）。
──────────────────
1. 触发时机
2	Hook	3	何时运行	4	是否阻塞渲染	5	典型用途
6	useMemo	7	渲染期间	8	是（同步）	9	昂贵计算、保持引用稳定
10	useCallback	11	渲染期间	12	是（同步）	13	保持函数引用不变，避免子组件无谓重渲染
14	useEffect	15	渲染之后	16	否（异步）	17	发请求、操作 DOM、订阅事件
	18	
──────────────────2. 参数与返回值• useMemo(fn, deps) → 值• useCallback(fn, deps) → 函数（等价于 useMemo(() => fn, deps)）• useEffect(fn, deps) → 无返回值（fn 可返回清理函数）
──────────────────3. 代码对照示例
function Demo({ id }) {
  const [count, setCount] = useState(0);

  /* 1. 缓存计算值 */
  const expensive = useMemo(() => {
    console.log('compute');
    return count * 2;
  }, [count]);

  /* 2. 缓存函数引用 */
  const handleClick = useCallback(() => {
    setCount(c => c + 1);
  }, []);

  /* 3. 副作用：渲染后打印日志、发请求 */
  useEffect(() => {
    console.log('id changed → 发请求', id);
    fetch(`/api/${id}`).then(...);

    return () => console.log('清理：取消订阅或中断请求');
  }, [id]);

  return (
    <>
      <div>{expensive}</div>
      <button onClick={handleClick}>+1</button>
    </>
  );
}
